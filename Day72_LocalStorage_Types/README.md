Day72 主要學習如何在 TypeScript 中使用 **LocalStorage** 儲存、讀取與管理資料，並透過 DOM 將資料顯示在網頁上。

本次練習涵蓋使用者資訊(User)與購物車(Cart)兩個案例，了解 Object 與 Array 在 LocalStorage 中的儲存方式，以及 JSON 資料轉換流程。
