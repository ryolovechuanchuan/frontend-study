# Day61_TypeScript_Setup

## 中文

### 📖 專案介紹

Day61 開始學習 TypeScript。

本日重點為建立 TypeScript 開發環境，了解 TypeScript 的編譯流程，並學習基本型別（Primitive Types）與 Type Inference（型別推論）。

---

### 🚀 學習目標

- 建立 TypeScript 開發環境
- 安裝 TypeScript Compiler（tsc）
- 建立 tsconfig.json
- 了解 TypeScript 編譯流程
- 學習 Primitive Types
- 學習 Type Inference
- 成功將 `.ts` 編譯成 `.js`

---

### 🛠️ 使用技術

- HTML5
- TypeScript
- JavaScript (Compiled)
- VS Code
